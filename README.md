# ydg_converter

This tool is specifically designed to convert the new .ydg image resource format found in the game "Relirium - Iseki to Deai to Bouken to"(Relirium -レリリウム- 遺跡と出逢いと冒険と) by Whirlpool into standard .png images.



How to Use?

Drag and drop one or multiple **.ydg** files onto the **ydg_converter.exe** to start the automatic conversion.
